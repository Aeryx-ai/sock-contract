# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting: https://github.com/Aeryx-ai/sock-contract/security/advisories/new

Do not open a public issue for a vulnerability. Include what you found, how to reproduce it and the version affected. We acknowledge reports and keep you informed until a fix ships.

## Supported versions

Only the latest tag is supported. Fixes land on `main` and ship in a new tag.
